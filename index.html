/ PROJETOS EM DESTAQUE

Cannolitsky (Dashboard Cannoli)

Problema: A startup Cannoli enfrentava processos manuais para analisar o desempenho de campanhas promocionais, atrasando a extração de insights.

Abordagem: Desenvolvemos um dashboard interativo integrado a IA. Liderei a modelagem de KPIs financeiros (receita, margem, CAC/LTV) e a implementação do painel financeiro, além de contribuir na arquitetura de software (diagramas UML).

Resultado: Automatização de insights sobre campanhas, centralização financeira e suporte rápido à decisão orientado a dados.

  • Python
  • Streamlit
  • Groq API (IA)
  • Google Colab
Repositório no GitHub

FourWare (App Mobile Comedoria da Tia)

Problema: O atendimento manual na cantina da FECAP gerava longas filas, lentidão nos pedidos e falta de controle automatizado de estoque.

Abordagem: Desenvolvemos um aplicativo mobile para pedidos antecipados. Fui responsável por UX (Wireframes, protótipos de alta fidelidade e Jornada do Usuário) e Cloud Native (CRUD, Fullstack e Banco de Dados em Contêineres).

Resultado: Digitalização do serviço, reduzindo o tempo de espera, otimizando o atendimento e automatizando a gestão.

  • Kotlin / Android
  • Firebase
  • Figma
Repositório no GitHub

Doatech (Dashboard Instituto Criativo)

Problema: A ONG Instituto Criativo sofria com a gestão descentralizada de eventos e doações, prejudicando a transparência e a prestação de contas.

Abordagem: Criação de uma plataforma web integrada para centralizar o controle gerencial. Liderei as frentes de desenvolvimento Full Stack e UI/UX Design (Figma), além de revisar todas as demais entregas do sistema.

Resultado: Atualização em tempo real de métricas e doações, garantindo maior eficiência administrativa e fortalecimento dos vínculos colaborativos.

  • React
  • Node.js
  • MySQL
  • Figma
Repositório no GitHub
